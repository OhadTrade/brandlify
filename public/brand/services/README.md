# Service illustrations v1

Five AI-generated raster illustrations based on the user-provided service-section reference and the approved `flowing-b.webp` logo reference. These are not SVGs or real-time 3D models. All custom agency branding uses the flowing lowercase b direction and BRANDLIFY spelling; platform symbols remain illustrative references, not endorsements.

The website uses 800px WebP derivatives (approximately 47-59 KB each), lazy loaded through Next Image. Desktop pointer tilt transforms only the illustrations; text and native links stay stable. Touch stays native and reduced-motion disables tilt.

Generated PNG originals are preserved in the local Codex generated-images directory. `scripts/prepare-service-art.mjs` can recreate the optimized assets when passed that directory. Do not replace the approved primary logo with a mark extracted from these mockups.
